# Knowledge Graph Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Store a job's Parse and Annotate results in an Apache AGE knowledge graph instead of JSON files in Blob, after first deleting mention detection and the Resolve step.

**Architecture:** `ParsedDocument` stays the in-memory form; a new `packages/knowledge-graph` maps it to AGE nodes and edges and back, and maps grounded classifications to nodes labeled by the IEEE 29148 ontology with `FROM` edges to their source elements. The web workflow shrinks to three operations (`upload`, `parse`, `annotate`) that write only to the graph and to Blob for binary content. Two PRs: a pure deletion PR, then the graph PR.

**Tech Stack:** TypeScript, Node 24, npm workspaces + Turborepo, Next.js 16, Vercel Workflow SDK, Drizzle + `pg`, Postgres 18 with Apache AGE 1.8, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-02-knowledge-graph-design.md`

## Global Constraints

- Vocabulary is fixed by the spec's table: steps Parse and Annotate; operations `upload`, `parse`, `annotate`; package `@dark-factory/knowledge-graph`; AGE graph `dark_factory`; canvas code in `apps/web/lib/canvas.ts`. Every name appears identically in code, canvas, URLs and prose.
- No caches and no intermediate JSON in Blob. Blob holds only `source.pdf` and `figures/<id>.png`.
- Graph nodes are labeled by the ontology (`FunctionalRequirement`, `UserClass`, ...) or by structure (`Document`, `Section`, `Paragraph`, `Table`, `Cell`, `Figure`). Never `Classification` or `Annotation`.
- No `LOAD 'age'` and no `SET search_path` in app code. The database is configured for that (done locally on 2026-10-02; the README documents it).
- No new environment variables. The knowledge-graph package reads `WORKFLOW_POSTGRES_URL`.
- The reading-order property is `position`, not `order` (`order` is a Cypher reserved word; verified on this AGE build). Every node carries `jobId` so ids like `paragraphs/0`, which repeat across jobs, can be matched within one job.
- `packages/parse` source is untouched. The parse and annotate CLIs keep writing local JSON as dev tools.
- Fixtures under `test/fixtures/` change only by recording, never by hand. The one derived fixture (`annotate.json`) is regenerated by replaying the recorded responses through `ground`.
- Critical tests only. Update existing tests; add exactly one new test file (the knowledge-graph round trip).
- No AI behavior changes. The prompt text is untouched.
- Never commit to `main`. Commit small, imperative mood. Push only to open the PR. PRs go through Cursor Origin via the `origin` skill (`.claude/skills/origin/SKILL.md`). Never merge.
- End every commit message with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>` and every PR description with `🤖 Generated with [Claude Code](https://claude.com/claude-code)`.

## Review Focus

1. A Workflow retry of `parse` writes the same job twice: there must be exactly one `Document` and no duplicated elements. Pinned in Task 6's round-trip test (writes twice, reads once).
2. `readDocument` for a job that has no graph yet must return `null`, so the pages answer 404 instead of crashing. Pinned in Task 6's round-trip test.
3. Element text with quotes, newlines or `$$` must survive the trip; it travels as a query parameter, never inlined into the Cypher string. Pinned in Task 6's round-trip test with a one-paragraph document.
4. Optional fields that are absent (`heading`, `role`, `caption`, `category`) must come back absent, not `null`. Pinned by the recorded fixtures in Task 6 and Task 7, which contain both cases.
5. Grounding warnings must land on the `annotate` operation row, not be lost when `ground` folds into the operation. Pinned in Task 10's web integration test.

- [ ] **Step 3: Rewrite `ground.ts`**

```ts
import type { Span } from "@dark-factory/parse";
import { z } from "zod";
import { CATEGORIES, TYPES, type AnnotateResult } from "./types.ts";

/** What the model returns. Quotes, never offsets. */
export const classificationSchema = z.object({
  elementId: z.string(),
  quote: z.string(),
  type: z.enum(TYPES),
  category: z.enum(CATEGORIES).nullable(),
});
export type ClassificationRow = z.infer<typeof classificationSchema>;

const wordChar = /[\p{L}\p{N}]/u;
/**
 * Model rows in, grounded classifications out. A row survives only if its
 * element exists and its quote is found verbatim, on word boundaries, inside
 * that element's text; everything else becomes a warning. This is the step
 * boundary AI output must cross.
 */
export function ground(
  rows: ClassificationRow[],
  anchors: Map<string, Span[]>,
  content: string,
): AnnotateResult {
  const result: AnnotateResult = { classifications: [], warnings: [] };

  /** Offset of `quote` inside element `elementId`, or -1 after pushing a warning. */
  const locate = (elementId: string, quote: string): number => {
    const spans = anchors.get(elementId);
    if (!spans) {
      result.warnings.push(`${elementId}: unknown element`);
      return -1;
    }
    for (const s of spans) {
      const end = s.offset + s.length;
      for (
        let i = content.indexOf(quote, s.offset);
        i >= 0 && i + quote.length <= end;
        i = content.indexOf(quote, i + 1)
      ) {
        const before = content[i - 1] ?? "";
        const after = content[i + quote.length] ?? "";
        if (!wordChar.test(before) && !wordChar.test(after)) return i;
      }
    }
    result.warnings.push(
      `${elementId}: quote not found: ${JSON.stringify(quote)}`,
    );
    return -1;
  };

  for (const row of rows) {
    const offset = locate(row.elementId, row.quote);
    if (offset < 0) continue;
    result.classifications.push({
      id: `a${result.classifications.length + 1}`,
      type: row.type,
      elementId: row.elementId,
      span: { offset, length: row.quote.length },
      text: row.quote,
      ...(row.category && { category: row.category }),
    });
  }
  return result;
}
```

- [ ] **Step 4: Rewrite `annotate.ts`**

```ts
import { createAzure } from "@ai-sdk/azure";
import type { ParsedDocument } from "@dark-factory/parse";
import { Output, generateText } from "ai";
import { mkdir, writeFile } from "node:fs/promises";
import { join } from "node:path";
import { anchors, chunk } from "./chunk.ts";
import {
  classificationSchema,
  ground,
  type ClassificationRow,
} from "./ground.ts";
import prompt from "./prompt.ts";
import type { AnnotateResult } from "./types.ts";

/** Azure AI Foundry deployment name. */
const MODEL = "gpt-4o";

/** One chunk of document text in, the model's rows out. Calls the model every time. */
export async function runAnnotate(text: string): Promise<ClassificationRow[]> {
  // Read per call, not at import: the integration test loads .env after importing this module.
  const baseURL = process.env.AZURE_FOUNDRY_ENDPOINT;
  if (!baseURL) throw new Error("AZURE_FOUNDRY_ENDPOINT is not set");
  const { output } = await generateText({
    model: createAzure({ baseURL })(MODEL),
    output: Output.array({ element: classificationSchema }),
    temperature: 0,
    instructions: prompt,
    prompt: text,
  });
  return output;
}

/**
 * ParsedDocument in, grounded classifications out. Every run calls the model;
 * nothing is reused between runs. Everything lands in `<outDir>/<sha256>/`:
 * one model call per chunk, raw responses in `annotate/<i>.json`, the
 * grounded result in `annotate.json`.
 */
export async function annotate(
  doc: ParsedDocument,
  outDir: string,
): Promise<AnnotateResult> {
  const dir = join(outDir, doc.source.sha256);
  await mkdir(join(dir, "annotate"), { recursive: true });
  // ponytail: all chunks in flight at once; add a concurrency cap if Azure rate limits bite.
  const outputs = await Promise.all(
    chunk(doc).map(async (text, i) => {
      const rows = await runAnnotate(text);
      await writeFile(
        join(dir, "annotate", `${i}.json`),
        JSON.stringify(rows, null, 2),
      );
      return rows;
    }),
  );
  const result = ground(outputs.flat(), anchors(doc), doc.content);
  await writeFile(join(dir, "annotate.json"), JSON.stringify(result, null, 2));
  return result;
}
```

```ts
/**
 * Live run against Azure AI Foundry, plus the eval: precision and recall per
 * classification type against `fixtures/expected.json`, which is written by a
 * human, never generated. Needs AZURE_FOUNDRY_ENDPOINT and AZURE_API_KEY in
 * the repo-root .env.
 */
import { existsSync, readFileSync, rmSync } from "node:fs";
import { fileURLToPath } from "node:url";
import { expect, test } from "vitest";
import { annotate } from "../src/annotate.ts";
import type { ClassificationType } from "../src/types.ts";
import { doc } from "./doc.ts";

const env = fileURLToPath(new URL("../../../.env", import.meta.url));
if (existsSync(env)) process.loadEnvFile(env);

const out = fileURLToPath(new URL("./out/", import.meta.url));
const expectedFile = new URL("./fixtures/expected.json", import.meta.url);

type Expected = {
  classifications: { elementId: string; type: ClassificationType }[];
};
type Scored = { elementId: string; type: ClassificationType };

/** Exact match on element and type, scored per type. */
function score(got: Scored[], want: Scored[]) {
  const key = (x: Scored) => `${x.elementId}|${x.type}`;
  const g = new Set(got.map(key));
  const w = new Set(want.map(key));
  const table: Record<
    string,
    { tp: number; fp: number; fn: number; precision: number; recall: number }
  > = {};
  for (const [type, items] of Map.groupBy([...got, ...want], (x) => x.type)) {
    const keys = new Set(items.map(key));
    const tp = [...keys].filter((k) => g.has(k) && w.has(k)).length;
    const fp = [...keys].filter((k) => g.has(k) && !w.has(k)).length;
    const fn = [...keys].filter((k) => !g.has(k) && w.has(k)).length;
    table[type] = {
      tp,
      fp,
      fn,
      precision: tp / (tp + fp || 1),
      recall: tp / (tp + fn || 1),
    };
  }
  return table;
}

// Raised by a human after reading the first run. 0 means "record, don't gate yet".
const FLOOR = 0;

test("live annotate and eval", { timeout: 300_000 }, async () => {
  rmSync(out, { recursive: true, force: true });
  const { classifications, warnings } = await annotate(doc, out);
  console.log(
    `${classifications.length} classifications, ${warnings.length} warnings`,
  );
  for (const w of warnings) console.log(`  ${w}`);
  if (!existsSync(expectedFile)) {
    console.log("fixtures/expected.json missing: recorded, not scored");
    return;
  }
  const expected: Expected = JSON.parse(readFileSync(expectedFile, "utf8"));
  const table = score(classifications, expected.classifications);
  console.table(table);
  for (const [type, { precision, recall }] of Object.entries(table)) {
    expect(precision, `${type} precision`).toBeGreaterThanOrEqual(FLOOR);
    expect(recall, `${type} recall`).toBeGreaterThanOrEqual(FLOOR);
  }
});
```

```ts
import type { Cell, Element, ParsedDocument } from "@dark-factory/parse";
import pg from "pg";

/** The one AGE graph; created by apps/web's migration. */
const GRAPH = "dark_factory";

let pool: pg.Pool | undefined;
// Opened on first use, not at import: tests load .env after importing this module.
const db = () =>
  (pool ??= new pg.Pool({
    connectionString: process.env.WORKFLOW_POSTGRES_URL,
  }));

type Row = Record<string, unknown>;

/**
 * Runs one Cypher query whose `$name` parameters come from `params` and
 * returns each row as the listed columns, decoded from agtype. Maps, lists,
 * strings and numbers print as JSON, so JSON.parse is the whole decoder.
 */
async function cypher<T extends unknown[]>(
  client: pg.ClientBase,
  query: string,
  params: Row,
  columns: string[] = ["v"],
): Promise<T[]> {
  const shape = columns.map((c) => `${c} agtype`).join(", ");
  const { rows } = await client.query<Record<string, string | null>>(
    `SELECT * FROM cypher('${GRAPH}', $$ ${query} $$, $1) AS (${shape})`,
    [JSON.stringify(params)],
  );
  return rows.map(
    (r) => columns.map((c) => (r[c] === null ? null : JSON.parse(r[c]!))) as T,
  );
}

async function transaction<T>(
  fn: (client: pg.PoolClient) => Promise<T>,
): Promise<T> {
  const client = await db().connect();
  try {
    await client.query("BEGIN");
    const out = await fn(client);
    await client.query("COMMIT");
    return out;
  } catch (err) {
    await client.query("ROLLBACK");
    throw err;
  } finally {
    client.release();
  }
}

/** Element kind to node label, and back. */
const LABEL = {
  section: "Section",
  paragraph: "Paragraph",
  table: "Table",
  figure: "Figure",
} as const;
const KIND = Object.fromEntries(
  Object.entries(LABEL).map(([kind, label]) => [label, kind]),
) as Record<string, keyof typeof LABEL>;

/** An element's node: its fields minus `parent`, `kind` (the label) and `cells`, plus `jobId` and its `position` in reading order. */
function elementProps(jobId: string, position: number, el: Element): Row {
  const row: Row = { ...el, jobId, position };
  delete row.parent;
  delete row.kind;
  delete row.cells;
  return row;
}

/** A cell's node: its fields minus `parent`, plus `jobId` and its `position` in the table's cell list. `kind` stays: for a cell it is data. */
function cellProps(jobId: string, position: number, cell: Cell): Row {
  const row: Row = { ...cell, jobId, position };
  delete row.parent;
  return row;
}

/** Replaces everything the graph holds for `jobId` with `doc`: the Document, one node per element and cell, IN edges up to the Document. */
export async function writeDocument(
  jobId: string,
  doc: ParsedDocument,
): Promise<void> {
  const nodes = new Map<string, Row[]>();
  const add = (label: string, row: Row) =>
    nodes.set(label, [...(nodes.get(label) ?? []), row]);
  const roots: string[] = [];
  const edges: { child: string; parent: string }[] = [];
  doc.elements.forEach((el, i) => {
    add(LABEL[el.kind], elementProps(jobId, i, el));
    if (el.parent === null) roots.push(el.id);
    else edges.push({ child: el.id, parent: el.parent });
    if (el.kind === "table")
      el.cells.forEach((cell, j) => {
        add("Cell", cellProps(jobId, j, cell));
        edges.push({ child: cell.id, parent: cell.parent ?? el.id });
      });
  });

  await transaction(async (client) => {
    await cypher(client, `MATCH (n {jobId: $jobId}) DETACH DELETE n`, {
      jobId,
    });
    await cypher(
      client,
      `CREATE (:Document {jobId: $jobId, sha256: $sha256, pages: $pages, content: $content, warnings: $warnings})`,
      { jobId, ...doc.source, content: doc.content, warnings: doc.warnings },
    );
    for (const [label, rows] of nodes)
      await cypher(client, `UNWIND $rows AS r CREATE (n:${label}) SET n = r`, {
        rows,
      });
    // ponytail: property matches with no index; add indexes on jobId and id when a write is measurably slow.
    await cypher(
      client,
      `MATCH (d:Document {jobId: $jobId}) UNWIND $roots AS id MATCH (c {jobId: $jobId, id: id}) CREATE (c)-[:IN]->(d)`,
      { jobId, roots },
    );
    await cypher(
      client,
      `UNWIND $edges AS e MATCH (c {jobId: $jobId, id: e.child}), (p {jobId: $jobId, id: e.parent}) CREATE (c)-[:IN]->(p)`,
      { jobId, edges },
    );
  });
}

/** The inverse of writeDocument, or null when the job has no Document. */
export async function readDocument(
  jobId: string,
): Promise<ParsedDocument | null> {
  return transaction(async (client) => {
    const [head] = await cypher<[Row]>(
      client,
      `MATCH (d:Document {jobId: $jobId}) RETURN properties(d)`,
      { jobId },
    );
    if (!head) return null;
    const { sha256, pages, content, warnings } = head[0] as {
      sha256: string;
      pages: number;
      content: string;
      warnings: string[];
    };
    const rows = await cypher<[string, Row, string, string | null]>(
      client,
      `MATCH (e {jobId: $jobId})-[:IN]->(p) RETURN label(e), properties(e), label(p), p.id`,
      { jobId },
    );
    const elements: Element[] = [];
    const cells = new Map<string, Cell[]>();
    for (const [label, props, parentLabel, parentId] of rows) {
      const { position, ...rest } = props as Row & { position: number };
      delete rest.jobId;
      const parent = parentLabel === "Document" ? null : parentId;
      if (label === "Cell") {
        const list = cells.get(parent!) ?? [];
        list[position] = { ...rest, parent } as Cell;
        cells.set(parent!, list);
      } else {
        const kind = KIND[label]!;
        elements[position] = { ...rest, parent, kind } as Element;
      }
    }
    for (const el of elements)
      if (el.kind === "table") el.cells = cells.get(el.id) ?? [];
    return { source: { sha256, pages }, content, elements, warnings };
  });
}
```

```ts
/** "non-functional-requirement" → "NonFunctionalRequirement", and back. The ontology names the labels. */
const toLabel = (type: string) =>
  type.replace(/(^|-)(\w)/g, (_, __, c: string) => c.toUpperCase());
const toType = (label: string) =>
  label
    .replace(/(?<!^)[A-Z]/g, (c) => `-${c}`)
    .toLowerCase() as ClassificationType;

/** Replaces the job's requirement nodes: one node per row, labeled by its type, with a FROM edge to the element it was quoted from. */
export async function writeRequirements(
  jobId: string,
  rows: Classification[],
): Promise<void> {
  const byLabel = new Map<string, Row[]>();
  for (const c of rows) {
    const label = toLabel(c.type);
    const props: Row = { jobId, id: c.id, text: c.text, span: c.span };
    if (c.category) props.category = c.category;
    byLabel.set(label, [
      ...(byLabel.get(label) ?? []),
      { elementId: c.elementId, props },
    ]);
  }
  await transaction(async (client) => {
    await cypher(
      client,
      `MATCH (r {jobId: $jobId})-[:FROM]->() DETACH DELETE r`,
      { jobId },
    );
    for (const [label, list] of byLabel)
      await cypher(
        client,
        `UNWIND $rows AS r MATCH (e {jobId: $jobId, id: r.elementId}) CREATE (n:${label})-[:FROM]->(e) SET n = r.props`,
        { jobId, rows: list },
      );
  });
}

/** The job's requirements in id order, each with the id of the element it came FROM. */
export async function readRequirements(
  jobId: string,
): Promise<Classification[]> {
  const rows = await transaction((client) =>
    cypher<[string, Row, string]>(
      client,
      `MATCH (r {jobId: $jobId})-[:FROM]->(e) RETURN label(r), properties(r), e.id`,
      { jobId },
    ),
  );
  return rows
    .map(([label, props, elementId]) => {
      const { id, text, span, category } = props as Pick<
        Classification,
        "id" | "text" | "span" | "category"
      >;
      return {
        id,
        type: toType(label),
        elementId,
        span,
        text,
        ...(category && { category }),
      };
    })
    .sort((a, b) => parseInt(a.id.slice(1)) - parseInt(b.id.slice(1)));
}
```

```ts
} from "@dark-factory/knowledge-graph";
import { eq } from "drizzle-orm";
import { FatalError } from "workflow";
import { getBlob, putBlob } from "@/lib/blob";
import { db, jobs } from "@/lib/db";
import { runOperation, setOperation } from "@/lib/operations";

async function setJob(jobId: string, patch: Partial<typeof jobs.$inferInsert>) {
  "use step";
  await db.update(jobs).set(patch).where(eq(jobs.id, jobId));
}

async function parseOperation(jobId: string) {
  "use step";
  return runOperation(jobId, "parse", "parse", async () => {
    const [job] = await db.select().from(jobs).where(eq(jobs.id, jobId));
    if (!job) throw new FatalError("job missing");
    const pdf = await getBlob(`${jobId}/source.pdf`);
    if (!pdf) throw new FatalError("source.pdf missing");
    const { result, figures } = await analyze(pdf);
    for (const { id, png } of figures)
      await putBlob(`${jobId}/figures/${id}.png`, png, "image/png");
    const doc = toParsedDocument(result, job.sha256);
    await writeDocument(jobId, doc);
    return { elements: doc.elements.length, warnings: doc.warnings.length };
  });
}

async function annotateOperation(jobId: string) {
  "use step";
  return runOperation(jobId, "annotate", "annotate", async () => {
    const doc = await readDocument(jobId);
    if (!doc) throw new FatalError("document missing from the knowledge graph");
    // ponytail: all chunks in flight at once; add a concurrency cap if Azure rate limits bite.
    const rows = (await Promise.all(chunk(doc).map(runAnnotate))).flat();
    const result = ground(rows, anchors(doc), doc.content);
    await writeRequirements(jobId, result.classifications);
    // Grounding warnings describe this run, not the document; runOperation's done patch leaves them in place.
    await setOperation(jobId, "annotate", "annotate", {
      warnings: result.warnings,
    });
    return {
      requirements: result.classifications.length,
      warnings: result.warnings.length,
    };
  });
}

/** One job down Station 1: Parse, then Annotate. The knowledge graph is the only thing that crosses a step boundary. */
export async function runJob(jobId: string) {
  "use workflow";
  await setJob(jobId, { status: "running" });
  try {
    await parseOperation(jobId);
    const counts = await annotateOperation(jobId);
    await setJob(jobId, { status: "done", finishedAt: new Date() });
    return counts;
  } catch (err) {
    const error = err instanceof Error ? err.message : String(err);
    await setJob(jobId, { status: "failed", error, finishedAt: new Date() });
    throw err;
  }
}
```
